# 철 기준 그림 — 원소 공방 화풍 그대로

원소 공방 생성기(`lib/prompt-element.js`, 기본 화풍 `jp_paint_anime`, element-atelier ece957c)가 짓는 철 스팀펑크 세계 그림 지시문에서 얼굴 말 둘만 뺀 것(안 (가) — 「moderately sized, realistically proportioned eyes — 」 · 「 with defined cheekbones」). 2.6 API 두 장(2026-11-11, 출력 2,264).
화풍공방 부품 조합이 아니라 비교 기준이라 색인(`index/`)에 넣지 않는다. 사용자 「우선 가로 바꾸고, 지금 원소공방 화풍으로 스팀펑크로 만들어줘」.

원래 지시문(얼굴 말 둘 그대로)으로도 두 장 — `*-original-*`(사용자 「원래 지시문으로도 그려줘」, 출력 2,264). 견줘 보니 얼굴 차이는 작다(원래 쪽 눈꼬리가 조금 더 날카로움) — 밝기 · 주황빛 · 녹 질감은 둘이 같다. 미형 · 밝기는 얼굴 말보다 화풍 문장(Luminous, rich colours) · 세계 빛 · 원소 재질 나열 쪽이 크다.

판타지 — 원래 · (가) 한 장씩(사용자 「판타지로 봐야겠다. 1장씩만 기존, 변경 으로 그려줘」, 출력 2,264). 얼굴 차이는 여기서도 작다 — 오히려 원래 쪽 눈이 조금 더 크다. 낮 하늘 + 녹은 쇳물 · 용비늘 갑옷 · 문장 깃발로 화면이 밝고 질감이 빽빽한 건 둘이 같다.
